# Go Go Day · 免费版和 Pro 版规划

给 Swift 版（App Store）用的规划。原则：**核心循环永远免费**，Pro 只放"更方便、更好看、更多设备"的东西，不卡住任何人开始做事。

---

## 收费方式

| 项目 | 内容 | 价格参考 |
|---|---|---|
| 免费下载 | 核心功能全部可用 | 0 |
| **Go Go Day Pro** | 一次性买断，永久解锁 | 8–15 美元（各地区按苹果价格档） |
| 支持开发者（打赏） | 不解锁任何东西，纯感谢 | 1.99 / 4.99 / 9.99 美元 |

- 不放广告
- 以后如果有了服务器成本（比如跨平台同步），再考虑加订阅，并保留买断选项

### Pro（一次性解锁）

| 功能 | 为什么放在 Pro |
|---|---|
| **桌面 / 锁屏小组件** | 今天的圆环 + 日期数字（每天变化）、下一件事和它的第一步 |
| **灵动岛 / 实时活动** | 休息中显示"接下来：晚饭"，到点可以直接开始 |
| **iCloud 同步** | iPhone、iPad、Mac 之间自动同步（CloudKit，对开发者几乎零成本） |
| **无限模版** | 周中、周日、旅行、考试周…… |
| **按星期自动换模版** | 比如周一到周五自动用"周中"，周末用"周日" |
| **更多主题配色** | 比如冷灰底、纯黑底、季节配色 |
| **可选 app 图标** | 设计过程中的候选图标都可以变成可选项（G 圆环、一件接一件、日出……） |
| **导出到日历** | 把一天的记录导出成日历事件，方便回看 |
| **更详细的回顾** | 每周 / 每月的节奏、各类别花了多少时间（只给想看的人，默认不打扰） |

## 上架前要准备

- [ ] Apple 开发者账号（每年 99 美元）——开发阶段可以先用免费 Apple ID 装到自己手机上
- [ ] 加入"小型企业计划"（苹果抽成从 30% 降到 15%）
- [ ] 隐私政策页、支持页（放在 GitHub Pages 即可，不需要买域名）
- [ ] App Store 隐私标签：数据全部在设备上 →"不收集数据"
- [ ] 欧盟"商家"身份声明：一旦收费就是商家，会公开地址 / 电话 / 邮箱——准备一个工作地址或代收地址、商务邮箱
- [ ] 中英文截图和介绍文案
- [ ] 确认"Go Go Day"这个名字在 App Store 里还能用
- [ ] 内购商品：Pro（非消耗型）、打赏三档（消耗型）
- [ ] "恢复购买"按钮（苹果审核必查）
